# store-graphics

Store screenshots and feature graphics for an app. [Maestro](https://maestro.dev) takes the screens of the real app (never committed),
[Open Screenshot Generator](https://github.com/dotnetdreamer/open-screenshot-generator) (osg) draws the store images around them,
in every language. Plain Node, run from the **app repo root**.

```
capture.mjs        maestro flows on simulators / emulators -> <store dir>/raw/<locale>/<app>/<target>/*.png
build-project.mjs  <store dir>/slides.json + locales -> osg projects; writes <store dir>/templates/ (no captures, committed)
render.mjs         osg render of the projects with the captures -> <fastlane>/<app id>/... (JPEG, feature graphic PNG)
font-preview.mjs   compare title fonts side by side
```

## What the app provides (default folder `graphics/store`, or `--dir <folder>`)

```
slides.json      { fastlane: "fastlane/metadata", apps: { <name>: { id, icon, theme, feature, slides, capture } } }
locales/*.json   every text of the images, one file per language (copy en-US.json)
maestro/*.yaml   the flows (and lib/ for shared steps) that navigate the app and take the screens
templates/       generated by build-project.mjs, committed
```

`apps.<name>`: `id` = package id (fastlane folder, app locale), `icon` = png path from the repo root, `theme` = `base`, `blobs[4]`,
`accent`, `title`, `subtitle`, `font` + `titleWeight` (only the families of `osg call list_fonts` exist), `feature.slides` = the 3 captures
in the feature graphic, `slides[]` = `{ id, layout: single|duo|sync, raw, raw2 }` (a slide shows `raw ?? id`; `duo`/`sync` put `raw2` behind),
`capture` = `{ flows: { "*": [yaml...], "<target>": [yaml...] }, dark: yaml, points: { "<target>": { NAME: "x%,y%" } } }`;
the points are passed to the flows as env (`${NAME}`), they depend on the layout of each device.
A flow ends with `- takeScreenshot: _end` (maestro never exits by itself: the script waits for that screenshot) and names its other screenshots
after the slides (`documents`, `crop`, ..., plus `dark` for the dark flow).

Targets: `ios-phone` 1320x2868, `ios-tablet` 2064x2752, `android-phone` 1440x2560, `android-tablet` 1600x2560, `feature` 1024x500.

## Use

```bash
npm install --prefix tools/store-graphics          # once. maestro (brew install maestro), Node >= 20.12
node tools/store-graphics/capture.mjs ios --phone <sim udid> --tablet <sim udid> [--locales en-US,fr-FR] [--app name]
node tools/store-graphics/capture.mjs android --phone emulator-5554 --tablet emulator-5556
node tools/store-graphics/render.mjs [--app --target --locales] [--fastlane /tmp/out]
node tools/store-graphics/build-project.mjs        # templates/
node tools/store-graphics/font-preview.mjs "Outfit:800" "Poppins:700" [--app name --target ios-phone]
```

`capture` sets the device language (the app follows it), dark mode and status bar. A locale without captures uses the ones of `en-US`.
Flows find buttons by text regexes with the words of every language (`(?i)^crop$|^recadrer$`).

Maestro gotchas: the `env:` defaults of a flow override `-e` (keep taps out of them), `${VAR}` is not resolved inside a nested
`runFlow when:` block, there is no sleep step. Android tablet: portrait is forced and the Gboard stylus dialog disabled; full screen
viewers that force landscape do not fit the tablet slots (leave those flows out of the tablet `flows`).
The osg projects: one artboard per slide, `localized[locale][elementId]` overlays for the texts, element names (`Title 1`, `Subtitle`,
`Pill text 2`, `Device front`) to find them in the osg editor (`osg studio --project templates/<file>.json`).
